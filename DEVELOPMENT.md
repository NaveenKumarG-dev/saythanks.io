### ☤ Variable Enviroments

To run the project, you need to set the following environment variables:

- MAILERSEND_API_KEY
- DATABASE_URL
- SENTRY_DSN
- AUTH0_DOMAIN
- AUTH0_JWT_V2_TOKEN
- AUTH0_CLIENT_ID
- AUTH0_CLIENT_SECRET
- AUTH0_CALLBACK_URL
